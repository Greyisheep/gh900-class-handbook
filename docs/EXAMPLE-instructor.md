# Instructor

**Role:** Facilitator, GH-900
**Team:** All of them

## Why I'm here

To prove that a repository is not a scary place, it's just a folder that remembers everything, plus a conversation around it.

## Three things I already knew

1. `main` used to be called `master`, and the rename was about inclusive language, not about anything technical.
2. Git was written by Linus Torvalds in 2005, the same person behind Linux. GitHub arrived three years later, in 2008.
3. A branch is not a copy of your project. It's a movable pointer to a single commit, which is exactly why branching costs nothing.

## Three things I did not

- [x] `git blame` is not about blame. It shows who last touched each line, so you know who to *ask*.
- [x] A "secret" Gist is unlisted, not private. Anyone with the link can read it.
- [x] Internal visibility, visible to everyone in the enterprise, only exists if you have an enterprise account.

## A command or concept I want to remember

```bash
# Fetch is the safe one: it downloads without touching your files.
git fetch

# Pull is fetch + merge. It downloads AND changes your working tree.
git pull
```
