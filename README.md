# GH-900 Class Handbook

Welcome. This repository is built **by the class, during the class**. By the end of the day every person here will have contributed a page to it, reviewed someone else's work, and watched the whole thing deploy to a live website.

## What you're going to do

1. Find the issue with your name on it in the [Issues](../../issues) tab.
2. Assign it to yourself.
3. Create a branch, add your page, open a pull request.
4. Review your pair's pull request. Get yours reviewed.
5. Merge — and watch your issue close by itself.

Full instructions are in [CONTRIBUTING.md](CONTRIBUTING.md). Read that first.

## The live site

Once Pages is switched on, this handbook is published at:

```
https://<owner>.github.io/gh900-class-handbook/
```

Your instructor will share the real URL in Block 3.

Those first five files are not decoration. They're the exact files GitHub looks for by name — when they exist, GitHub surfaces them as badges and shortcuts on the repository home page. Scroll up and look at the sidebar; that's them working.

## House rules

- Small commits, with messages that say **why**, not what.
- Branches are named `type/short-description` — lowercase, hyphenated, describing
  the work rather than the person. Yours today is `docs/add-<yourname>-page`.
  The full convention is in [CONTRIBUTING.md](CONTRIBUTING.md) and it's worth two minutes.
- Be kind in review. Every person here is learning something today.
