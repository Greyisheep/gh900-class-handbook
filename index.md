### How to add your row

Replace an empty row in **your team's** table with your details:

```markdown
| Amara | [amara](docs/amara.md) | Squash and merge collapses a whole branch into one commit |
```

Keep the pipes. Keep the table on your team's section. Add rows in the order people finish — don't reorganise anyone else's line.

---

<sub>Team names are the four object types Git actually stores: a <b>blob</b> is file content, a <b>tree</b> is a directory, a <b>commit</b> is a snapshot with a parent, and a <b>tag</b> is a label on an important commit. You are, briefly, a Git object.</sub>
